# Деплой FinAI на Vercel

## 🚀 Быстрый старт

### 1. Подготовка проекта
Проект уже настроен для деплоя на Vercel. Созданы все необходимые файлы:
- `vercel.json` - основная конфигурация Vercel
- `package.json` - конфигурация сборки
- `.vercelignore` - исключения для деплоя
- `vercel-init-db.php` - инициализация базы данных

### 2. Деплой на Vercel

#### Вариант A: Через Vercel CLI (Рекомендуется)

1. **Установите Vercel CLI**
   ```bash
   npm i -g vercel
   ```

2. **Войдите в аккаунт Vercel**
   ```bash
   vercel login
   ```

3. **Деплой проекта**
   ```bash
   vercel
   ```

4. **Настройте переменные окружения**
   ```bash
   vercel env add COOKIE_VALIDATION_KEY
   vercel env add SALT
   # Добавьте остальные переменные из env.vercel.example
   ```

5. **Добавьте MySQL базу данных**
   - В панели Vercel перейдите в раздел Storage
   - Добавьте MySQL базу данных
   - Vercel автоматически создаст переменные окружения

#### Вариант B: Через веб-интерфейс

1. **Подключите репозиторий**
   - Зайдите на [vercel.com](https://vercel.com)
   - Нажмите "New Project"
   - Подключите ваш GitHub репозиторий

2. **Настройте проект**
   - Framework Preset: Other
   - Root Directory: ./
   - Build Command: `composer install --no-dev --optimize-autoloader`
   - Output Directory: `web`

3. **Добавьте переменные окружения**
   - В настройках проекта перейдите в Environment Variables
   - Добавьте переменные из `env.vercel.example`

4. **Добавьте MySQL базу данных**
   - В разделе Storage добавьте MySQL
   - Vercel создаст переменные: `MYSQL_HOST`, `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD`

### 3. Инициализация базы данных

После деплоя выполните инициализацию базы данных:

```bash
# Через Vercel CLI
vercel env pull .env.local
php vercel-init-db.php

# Или через веб-интерфейс Vercel
# Запустите функцию инициализации в Functions секции
```

### 4. Настройка домена (опционально)

1. **Добавьте кастомный домен**
   - В настройках проекта перейдите в Domains
   - Добавьте ваш домен
   - Настройте DNS записи

2. **Обновите переменные окружения**
   ```bash
   vercel env add APP_URL production
   # Введите ваш домен: https://yourdomain.com
   ```

## 📁 Структура файлов для Vercel

```
├── vercel.json              # Конфигурация Vercel
├── package.json             # Конфигурация сборки
├── .vercelignore            # Исключения для деплоя
├── vercel-init-db.php       # Инициализация БД
├── env.vercel.example       # Шаблон переменных окружения
└── config/
    ├── bootstrap.php        # Загрузка переменных окружения
    ├── db.php              # Конфигурация БД (с поддержкой Vercel)
    ├── web.php             # Основная конфигурация
    └── params.php          # Параметры приложения
```

## 🔧 Конфигурация

### vercel.json
```json
{
  "version": 2,
  "builds": [
    {
      "src": "web/index.php",
      "use": "@vercel/php"
    }
  ],
  "routes": [
    {
      "src": "/(.*)",
      "dest": "web/index.php"
    }
  ],
  "env": {
    "YII_ENV": "production",
    "YII_DEBUG": "false"
  }
}
```

### Переменные окружения

**Обязательные:**
- `COOKIE_VALIDATION_KEY` - ключ для валидации cookies (32+ символов)
- `SALT` - соль для хеширования паролей

**Автоматические (Vercel MySQL):**
- `MYSQL_HOST`
- `MYSQL_DATABASE`
- `MYSQL_USER`
- `MYSQL_PASSWORD`
- `MYSQL_PORT`

**Опциональные:**
- `MAIL_FROM`, `MAIL_HOST`, `MAIL_USER`, `MAIL_PASSWORD` - настройки email
- `TFBANK_USERNAME`, `TFBANK_PASSWORD` - API банков
- `APP_NAME`, `TIMEZONE` - настройки приложения

## 🚨 Важные особенности

### 1. Ограничения Vercel
- **Время выполнения функции**: максимум 30 секунд
- **Размер файлов**: максимум 50MB
- **Память**: максимум 1024MB

## 🆘 Решение проблем

### Проблема: Ошибка подключения к базе данных
**Решение:**
1. Проверьте переменные окружения MySQL
2. Убедитесь, что база данных создана
3. Запустите `vercel-init-db.php`

### Проблема: Медленная загрузка
**Решение:**
1. Проверьте размер проекта (должен быть < 50MB)
2. Убедитесь, что .vercelignore исключает ненужные файлы
3. Оптимизируйте автозагрузчик Composer

### Проблема: Ошибка 500
**Решение:**
1. Проверьте логи в панели Vercel
2. Убедитесь, что все переменные окружения настроены
3. Проверьте права доступа к файлам
