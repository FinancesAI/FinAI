# Деплой FinAI на Railway

## Быстрый старт

### 1. Подготовка проекта
Проект уже настроен для деплоя на Railway. Все необходимые файлы созданы:
- `railway.json` - конфигурация Railway
- `nixpacks.toml` - конфигурация сборки
- `Procfile` - команда запуска
- `init-db.php` - инициализация базы данных

### 2. Деплой на Railway

1. **Подключите репозиторий к Railway**
   - Зайдите на [railway.app](https://railway.app)
   - Создайте новый проект
   - Подключите ваш GitHub репозиторий

2. **Добавьте MySQL базу данных**
   - В панели Railway добавьте MySQL сервис
   - Railway автоматически создаст переменные окружения:
     - `MYSQL_HOST`
     - `MYSQL_DATABASE`
     - `MYSQL_USER`
     - `MYSQL_PASSWORD`

3. **Настройте переменные окружения**
   - В настройках проекта добавьте переменные из `env.example`
   - **ОБЯЗАТЕЛЬНО** сгенерируйте новые ключи:
     - `COOKIE_VALIDATION_KEY` - случайная строка 32+ символов
     - `SALT` - случайная строка для хеширования

4. **Деплой**
   - Railway автоматически соберет и задеплоит проект
   - База данных будет инициализирована автоматически
   - Миграции выполнятся при сборке

### 3. Настройка после деплоя

1. **Проверьте работу приложения**
   - Откройте URL, предоставленный Railway
   - Убедитесь, что приложение загружается

2. **Настройте email (опционально)**
   - Добавьте переменные для вашего SMTP сервера
   - Или используйте сервис типа SendGrid, Mailgun

3. **Настройте банковские API (опционально)**
   - Добавьте API ключи для банковских интеграций
   - Настройте webhook URL для получения уведомлений

### 4. Мониторинг

- Логи доступны в панели Railway
- Мониторинг производительности встроен
- Автоматические перезапуски при сбоях

## Структура файлов для Railway

```
├── railway.json          # Конфигурация Railway
├── nixpacks.toml         # Конфигурация сборки
├── Procfile              # Команда запуска
├── init-db.php           # Инициализация БД
├── env.example           # Шаблон переменных окружения
└── config/
    ├── bootstrap.php     # Загрузка переменных окружения
    ├── db.php            # Конфигурация БД
    ├── web.php           # Основная конфигурация
    └── params.php        # Параметры приложения
```
