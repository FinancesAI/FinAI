# FinAI - Система управления кредитными заявками

## Быстрый старт

### 1. Установка зависимостей
```bash
composer install
```

### 2. Настройка переменных окружения
Скопируйте файл `env.example` в `.env` и заполните необходимые параметры:

```bash
cp env.example .env
```

Отредактируйте `.env` файл:
```env
# Database Configuration
DB_HOST=localhost
DB_NAME=finlatlv_app
DB_USER=finlatlv_app
DB_PASSWORD=your_secure_password_here

# Security
COOKIE_VALIDATION_KEY=your_secure_cookie_key_here
SALT=your_secure_salt_here

# Application
APP_NAME=FinAI
APP_URL=https://your-domain.ru
TIMEZONE=Europe/Moscow
```

### 3. Настройка базы данных
Создайте базу данных и выполните миграции:
```bash
php yii migrate
```

### 4. Настройка веб-сервера
Настройте веб-сервер на папку `web/`
